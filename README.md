Option Pricing Analytics Engine & Interactive Dashboard

A Streamlit-based interactive tool for European/American option pricing, supporting 7 core algorithms and real-time comparative analysis.

Features
Support European/American option pricing with 7 algorithms:
Black-Scholes (Analytical)
Monte Carlo Simulation
Binomial Tree / Trinomial Tree (American)
Finite Difference Method (European/American)
Longstaff-Schwartz Method (LSM, American)
Early exercise optimization for American options
Real-time parameter adjustment & dynamic UI
95% confidence intervals (Monte Carlo)
Convergence analysis against BSM analytical benchmarks
Progress tracking for large-scale simulations

Usage
Select option type (European/American) in the sidebar
Adjust core parameters (stock price, strike price, volatility, etc.)
Choose calculation algorithms (multiple optional)
Click "Calculate" to view results
Compare prices, computation time and convergence metrics
